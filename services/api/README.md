# API / detector service boundary

This directory deliberately does **not** contain the AI Studio Express/Gemini server or URL fetcher.

Instrument Alpha should first prove a bounded four-mechanism intrinsic detector. `detector_contract.py` is the network-free validation boundary for that future Python service: exact spans, strict enums, nonempty structured criteria, repeated-excerpt disambiguation, and an explicit ban on cross-document mechanisms in the intrinsic slice.

The next implementation step is to place candidate generation and contextual verification behind this contract, then build the human-reviewed benchmark. URL ingestion remains deferred until Instrument Alpha is credible.
